# Spec Delta

## Purpose

让每个关卡有自己的外观：整关主题一键套用，天空可选纯色或渐变，地面、草皮、砖块、硬块和水管可以单独配色。配色写在关卡数据里，在游戏和编辑器中显示一致，并能在色彩能力较弱的终端上合理降级。

## ADDED Requirements

### Requirement: 配色是关卡数据的一部分

关卡文件 MUST 支持一个可选的外观配置，包括：主题名、天空、地面、草皮、砖块、硬块、水管。没有外观配置的关卡 MUST 与当前游戏外观完全一致。外观配置 MUST 只影响该关卡的画面，MUST NOT 影响 HUD、菜单和其他关卡。

#### Scenario: 旧关卡外观不变
- **WHEN** 加载一个没有外观配置的关卡
- **THEN** 画面与本变更之前逐像素一致

#### Scenario: 只影响本关
- **WHEN** 玩家先玩一个雪原主题的关卡，再从选关进入 1-1
- **THEN** 1-1 显示它自己的配色，不残留雪原配色

### Requirement: 整关主题预设

系统 MUST 内置至少 8 套整关主题：草原、黄昏、夜晚、黎明、雪原、沙漠、地下、熔岩。每套主题 MUST 同时给定天空、地面、草皮、砖块、硬块与水管的配色，并且彼此搭配协调。指定主题后，单项配置 MUST 覆盖主题中的对应项，其余项沿用主题。

#### Scenario: 一套主题换装整关
- **WHEN** 关卡外观设为"雪原"主题，没有其他单项配置
- **THEN** 天空、地面、草皮、砖块、硬块、水管全部显示雪原配色

#### Scenario: 主题加单项覆盖
- **WHEN** 关卡设为"沙漠"主题，并单独把水管设为蓝色
- **THEN** 水管为蓝色，其余元素保持沙漠配色

### Requirement: 天空

天空 MUST 支持两种形式：一种纯色，或从顶到地平线的上下两色渐变。天空 MUST 能选内置预设（至少：白天蓝、黄昏橙、夜空、黎明粉、阴天灰、星空），也 MUST 能用任意 RGB 颜色自定义。云的颜色 MUST 随天空明暗自动调整，保证云始终看得见。

#### Scenario: 渐变天空
- **WHEN** 天空设为从深蓝到橙色的渐变
- **THEN** 画面顶部为深蓝，越往下越橙，过渡平滑、不出现明显断层（真彩色终端下）

#### Scenario: 亮天空上的云
- **WHEN** 天空设为很浅的白天蓝
- **THEN** 云的颜色与天空可区分，不会融进背景

### Requirement: 元素配色

地面与草皮、砖块、硬块、水管 MUST 各自支持从内置色板中选择，也 MUST 支持自定义 RGB。元素的高光、阴影、砖缝、土层等配套色 MUST 由主色自动推出，设计者只选一种主色。内置色板 MUST 至少包含：草皮——草地绿、秋草橙、雪地白、沙漠黄、紫晶；砖块——红砖、蓝砖、石砖、金砖；水管——绿、蓝、橙、灰。

#### Scenario: 换砖块颜色
- **WHEN** 砖块选为"蓝砖"
- **THEN** 所有砖块显示蓝色砖面，砖缝与阴影是相应的深蓝，而不是原来的红色系

#### Scenario: 自定义草皮色
- **WHEN** 草皮设为自定义的粉色
- **THEN** 草皮的两种交替图案都用粉色系的明暗绘制

### Requirement: 终端降级

在只支持 256 色的终端上，每种配色 MUST 映射为最接近的可用颜色；渐变天空 MUST 量化为若干色带，不能直接变成一种颜色。在单色终端上，MUST 忽略外观配置，按现有单色方案显示。降级 MUST NOT 让前景元素与天空变成同一种颜色。

#### Scenario: 256 色下的渐变
- **WHEN** 在 256 色终端中玩一个渐变天空的关卡
- **THEN** 天空显示为几条由深到浅的色带

#### Scenario: 降级不糊成一片
- **WHEN** 某关卡的砖块颜色与天空颜色在 256 色下会映射为同一色号
- **THEN** 砖块改用相邻的可区分色号显示

### Requirement: 外观在编辑器中可视化配置

编辑器 MUST 提供外观面板：主题以缩略预览卡片的形式列出，点击即套用；天空、草皮、砖块、硬块、水管各有色板与拾色器；天空可切换纯色或渐变。任何改动 MUST 立即反映在画布上，并且 MUST 可撤销。外观面板 MUST 有"恢复主题默认"按钮，清除所有单项覆盖。

#### Scenario: 套用主题
- **WHEN** 用户在外观面板点击"熔岩"卡片
- **THEN** 画布立即换成熔岩配色，撤销一次即恢复原样

#### Scenario: 清除覆盖
- **WHEN** 用户单独改了水管和砖块颜色后，点"恢复主题默认"
- **THEN** 水管与砖块回到当前主题的配色

### Requirement: 配色对比提示

设计检查 MUST 在以下情况给出提示：砖块、问号块、金币、敌人或玩家与天空的颜色对比过低，难以分辨。提示 MUST 指明是哪两种颜色冲突。

#### Scenario: 金币看不清
- **WHEN** 天空设为与金币接近的金黄色
- **THEN** 检查结果提示金币与天空对比不足

# Spec Delta

## Purpose

定义社区关卡从"画好"到"收进游戏"要满足的条件：关卡文件携带的元信息、两级设计检查（错误与提示）、仓库内关卡的自动校验，以及贡献者照着做就能提交的指南与命名规则。

## ADDED Requirements

### Requirement: 关卡元信息

关卡文件 MUST 支持以下可选元信息：标题、作者、简介、难度（1 到 5）。外观配置与随机内容物的数据要求分别见 `level-appearance` 与 `random-block-content`。没有这些字段的旧关卡文件 MUST 照常加载。字段长度 MUST 有上限，超长或难度越界 MUST 作为加载错误报告。

#### Scenario: 旧关卡照常加载
- **WHEN** 加载一个没有任何元信息字段的关卡文件
- **THEN** 加载成功，标题显示为关卡标识，作者与简介为空

#### Scenario: 难度越界
- **WHEN** 关卡文件中难度写为 7
- **THEN** 加载失败，错误信息指出难度必须在 1 到 5 之间

### Requirement: 单一校验来源

编辑器、试玩、游戏加载与自动测试 MUST 使用同一套关卡校验规则，任何一处接受的关卡在其他各处也 MUST 被接受，任何一处拒绝的关卡在其他各处也 MUST 被拒绝。

#### Scenario: 编辑器与游戏结论一致
- **WHEN** 编辑器对某关卡没有报告任何错误
- **THEN** 游戏加载该关卡文件时也不报错

#### Scenario: 游戏会拒绝的编辑器先拒绝
- **WHEN** 关卡中的隐藏块被放在了实心砖块的位置
- **THEN** 编辑器把它报为错误，与游戏加载时的拒绝原因一致

### Requirement: 两级设计检查

编辑器 MUST 在每次编辑后自动重新检查关卡，把问题分为"错误"与"提示"两级并列表显示。错误是游戏会拒绝加载的问题，会阻止保存与试玩；提示是能加载但很可能玩不好的设计问题，不阻止保存。每条问题 MUST 带有坐标，点击后画布 MUST 跳转并高亮对应格子。

#### Scenario: 实时更新
- **WHEN** 用户给一个缺少内容物的问号块设置了内容物
- **THEN** 问题列表中对应的错误立即消失

#### Scenario: 点击定位
- **WHEN** 用户点击一条位于第 150 列的问题
- **THEN** 画布滚动到第 150 列，并高亮该格

### Requirement: 设计提示项

设计检查 MUST 至少给出以下提示：出生点下方没有地面；出生点附近若干格内有敌人；按游戏物理计算，有坑宽到奔跑也跳不过去；有实心障碍高到满跳也越不过且无法绕行；从出生点出发无法到达旗杆；问号块正下方没有空间，因而无法被顶到；敌人生成在实心格内或悬空；前景元素与天空颜色对比过低。跳跃距离与高度的判断 MUST 来自游戏的物理参数，不得写死数值。

#### Scenario: 坑太宽
- **WHEN** 关卡中有一个宽 12 格的坑，两侧没有任何垫脚处
- **THEN** 问题列表给出"坑可能跳不过去"的提示，并标出该坑

#### Scenario: 方块被封住
- **WHEN** 一个问号块正下方紧挨着一个砖块
- **THEN** 问题列表提示该问号块无法从下方顶到

#### Scenario: 颜色对比过低
- **WHEN** 天空颜色与砖块颜色几乎相同
- **THEN** 问题列表提示砖块与天空难以分辨

#### Scenario: 物理参数变化后结论跟着变
- **WHEN** 游戏的跳跃参数被调高，使原本跳不过的坑变得可以跳过
- **THEN** 同一关卡不再给出这条提示

### Requirement: 仓库关卡自动校验

项目的自动测试 MUST 加载仓库中的每一个内置关卡，任何一个关卡出现"错误"级问题时测试 MUST 失败，并报告关卡名与具体位置。自动测试 MUST 检查每个关卡文件的排版与编辑器保存的排版一致。

#### Scenario: 坏关卡进不来
- **WHEN** 有人提交了一个行宽与声明宽度不符的关卡文件
- **THEN** 测试失败，指出是哪个关卡的哪一行

#### Scenario: 手改后排版漂移
- **WHEN** 有人手工编辑关卡文件，改乱了缩进
- **THEN** 测试失败，提示用编辑器重新保存或运行格式化命令

### Requirement: 关卡标识与命名

每个内置关卡 MUST 有唯一的标识，标识即文件名，只允许小写字母、数字和连字符。官方关卡使用 `<世界>-<关>` 形式（如 `1-2`）；社区关卡 MUST 使用 `c-<作者>-<名称>` 形式，避免与官方关卡冲突。编辑器保存时 MUST 校验标识格式。

#### Scenario: 非法标识
- **WHEN** 用户把关卡标识填为 `My Level!`
- **THEN** 编辑器拒绝保存，提示允许的字符

#### Scenario: 社区关卡命名
- **WHEN** 作者 `tom` 保存一个名为 `sky-run` 的社区关卡
- **THEN** 文件名为 `c-tom-sky-run.json`

### Requirement: 贡献指南

仓库 MUST 提供一份关卡贡献指南，说明：如何启动编辑器、如何试玩、命名规则、提交前必须通过的检查，以及提 PR 的步骤。按照指南操作 MUST 不需要阅读任何 Go 或 Python 代码。

#### Scenario: 新人照指南提交
- **WHEN** 一个只会用浏览器和 git 的贡献者按指南操作
- **THEN** 能做出一个通过全部检查的关卡并提交 PR

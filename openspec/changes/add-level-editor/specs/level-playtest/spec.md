# Spec Delta

## Purpose

让关卡设计者在编辑器里一键试玩正在编辑的关卡。试玩跑的是游戏本体的物理、敌人和渲染，所以试玩里的手感就是正式游戏里的手感。玩完立刻回到编辑原处，形成"画—玩—改"的快速循环。

## ADDED Requirements

### Requirement: 一键试玩

编辑器 MUST 提供一个快捷键与按钮，在编辑器页面内立即开始试玩当前关卡，包括尚未保存的改动。从按下到可以操作 MUST 在 1 秒以内。关卡有"错误"级检查问题时 MUST NOT 开始试玩，并定位到第一个错误。

#### Scenario: 未保存的改动也能玩
- **WHEN** 用户刚放下一根水管还没保存，按下试玩键
- **THEN** 试玩中出现这根水管

#### Scenario: 有错误时不能试玩
- **WHEN** 关卡缺少出生点时按试玩键
- **THEN** 不进入试玩，编辑器提示缺少出生点

### Requirement: 试玩与正式游戏一致

试玩 MUST 使用与正式游戏相同的物理参数、碰撞、敌人行为、方块与道具规则、计分和通关判定。同一关卡、同一串按键输入在试玩和正式游戏中 MUST 得到相同的结果。试玩画面 MUST 使用游戏的素材与配色。

#### Scenario: 跳跃高度一致
- **WHEN** 在试玩中原地满跳
- **THEN** 跳起的高度与终端游戏中一致，都能越过 4 格高的水管

#### Scenario: 输入回放一致
- **WHEN** 把同一关卡、同一串逐帧输入分别交给试玩和正式游戏的模拟
- **THEN** 两边最终的玩家位置、分数和通关结果完全相同

### Requirement: 选择起点

试玩 MUST 支持两种起点：从关卡出生点开始，以及从鼠标所在的列开始。从指定列开始时，玩家 MUST 落在该列最高的可站立位置上；该列没有可站立位置时 MUST 改用出生点并提示。

#### Scenario: 从当前位置开始
- **WHEN** 用户把鼠标停在第 120 列，按"从这里试玩"
- **THEN** 玩家出现在第 120 列的地面上，镜头对准那里

#### Scenario: 该列是坑
- **WHEN** 鼠标所在列是一个坑，用户按"从这里试玩"
- **THEN** 试玩从出生点开始，并提示该列没有落脚点

### Requirement: 回到编辑

试玩中按 Esc、玩家死亡或通关时，MUST 立即回到编辑状态，画布视图 MUST 停在玩家最后所在的位置。试玩 MUST NOT 修改关卡内容：试玩中被打碎的砖块、拿走的金币和顶过的问号块，回到编辑后都 MUST 恢复原样。

#### Scenario: 死亡后回到原处
- **WHEN** 玩家在第 80 列附近掉进坑里
- **THEN** 编辑器回到编辑状态，视图停在第 80 列附近

#### Scenario: 关卡不被改动
- **WHEN** 玩家在试玩中打碎一排砖块后按 Esc
- **THEN** 编辑画布上那排砖块仍在

### Requirement: 试玩选项

试玩 MUST 提供以下开关：以大马里奥开始、无敌（不会死亡）；随机方块相关的固定种子、换种子与显示随机结果见 `random-block-content`。这些开关 MUST 只影响试玩，MUST NOT 写进关卡文件。

#### Scenario: 无敌模式检查后段
- **WHEN** 用户打开无敌开关后试玩
- **THEN** 碰到敌人或掉进坑都不会死亡，可以一直玩到关卡结尾

#### Scenario: 选项不进文件
- **WHEN** 打开"大马里奥开始"后保存关卡
- **THEN** 关卡文件中没有任何试玩选项

### Requirement: 轨迹回放

编辑器 MUST 记录最近一次试玩中玩家的移动轨迹，回到编辑后在画布上叠加显示，并标出死亡点与跳跃起点。轨迹 MUST 可以隐藏，并在关卡被编辑后标记为过期。

#### Scenario: 查看跳跃轨迹
- **WHEN** 用户试玩时在一个坑前起跳后掉了下去，回到编辑
- **THEN** 画布上显示这次跳跃的弧线，弧线终点标为死亡点

#### Scenario: 编辑后轨迹过期
- **WHEN** 显示轨迹时用户修改了关卡
- **THEN** 轨迹变淡并标注为旧轨迹

### Requirement: 试玩操作

试玩 MUST 使用与终端游戏相同的默认键位（移动、跑、跳、暂停），并支持同时按住多个键；浏览器能拿到松键事件，因此 MUST 按真实的按下与松开处理，不使用终端那种松键超时。编辑器的快捷键在试玩期间 MUST 失效，Esc 除外。

#### Scenario: 跑跳同时按
- **WHEN** 试玩中同时按住右、跑和跳
- **THEN** 玩家冲刺起跳

#### Scenario: 编辑快捷键不误触
- **WHEN** 试玩中按下编辑器的撤销快捷键
- **THEN** 关卡没有被撤销，试玩继续

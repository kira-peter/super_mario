# Spec Delta

## Purpose

在标题页让玩家从全部内置关卡中挑一关来玩，显示每关的标题、作者与难度，使社区贡献的关卡一合并进仓库就能被玩到。

## ADDED Requirements

### Requirement: 选关入口

标题页主菜单 MUST 有一项"选择关卡"，进入后列出全部内置关卡。只有一个内置关卡时，该入口仍 MUST 可用。"开始游戏" MUST 保持直接进入 1-1 的行为。

#### Scenario: 进入选关
- **WHEN** 玩家在标题页选择"选择关卡"
- **THEN** 显示内置关卡列表

#### Scenario: 开始游戏不变
- **WHEN** 玩家在标题页选择"开始游戏"
- **THEN** 直接开始 1-1

### Requirement: 关卡列表内容与顺序

列表 MUST 包含内置关卡和本地关卡（游戏程序旁 `levels/` 目录里的关卡），先列内置、后列本地；内置中官方关卡按世界与关号排序在前，社区关卡按标题排序在后。同名的内置与本地关卡 MUST 都列出，本地的标注"本地"。每一项 MUST 显示标题，以及作者与难度（有的话）；当前高亮项 MUST 额外显示简介。

#### Scenario: 排序
- **WHEN** 内置关卡有 `1-1`、`1-2` 和两个社区关卡
- **THEN** 列表顺序为 1-1、1-2，然后是按标题排序的两个社区关卡

#### Scenario: 元信息缺省
- **WHEN** 某关卡没有标题与作者
- **THEN** 列表用关卡标识作为标题，作者一栏留空，不显示占位文字

### Requirement: 选择与返回

列表 MUST 支持方向键移动、回车开始、Esc 返回主菜单。一个关卡通关、游戏结束或从暂停菜单退出后，MUST 回到选关列表并高亮刚玩过的关卡。

#### Scenario: 选中开始
- **WHEN** 玩家在列表中高亮一个社区关卡并按回车
- **THEN** 游戏以该关卡开始

#### Scenario: 玩完回到列表
- **WHEN** 从选关进入的关卡通关并看完结算
- **THEN** 回到选关列表，高亮刚才那一关

### Requirement: 按关卡记录成绩

排行榜成绩 MUST 记录所属关卡，同名的内置与本地关卡分开记录；选关列表中每一项 MUST 显示该关卡的最高分（有的话）。

#### Scenario: 显示本关最高分
- **WHEN** 玩家在某社区关卡上拿到过 12000 分
- **THEN** 选关列表中该关卡旁显示 12000

### Requirement: 本地关卡不用重新编译

放进本地关卡目录的关卡文件 MUST 在下次打开选关列表时出现，不需要重新编译游戏。在仓库里运行时，内置关卡 MUST 从仓库目录读取，使编辑器刚保存的关卡立即可选。无法加载的本地文件 MUST 被跳过，MUST NOT 影响游戏启动。

#### Scenario: 拷来的关卡
- **WHEN** 把别人给的 `c-amy-hills.json` 放进程序旁的 `levels/` 后打开选关
- **THEN** 列表里出现这一关，标注"本地"，可以直接开始

#### Scenario: 坏文件不影响
- **WHEN** `levels/` 里有一个格式错误的文件
- **THEN** 列表里没有它，其他关卡照常可选

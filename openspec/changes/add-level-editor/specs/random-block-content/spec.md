# Spec Delta

## Purpose

让问号块和隐藏块的内容物既可以由设计者指定，也可以从设计者给定的候选池里按权重随机抽取。抽取在每条命开始时完成，同一种子下结果完全可复现，所以随机不会破坏回放和测试。

## ADDED Requirements

### Requirement: 指定或随机

问号块与隐藏块的内容物 MUST 二选一：指定（金币、红蘑菇、星星、1UP、毒蘑菇、金币袋中的一种），或随机。未声明随机的方块 MUST 按指定处理，旧关卡文件 MUST 行为不变。

#### Scenario: 旧关卡不变
- **WHEN** 加载一个所有方块都只写了单一内容物的旧关卡
- **THEN** 每个方块产出的内容与之前完全相同

#### Scenario: 随机块
- **WHEN** 一个方块设为随机，候选为红蘑菇、星星、1UP
- **THEN** 顶它产出这三种之一，不会产出不在候选里的内容

### Requirement: 候选池与权重

随机方块 MUST 声明候选池：每一项是一种内容物加一个非负整数权重。抽中某项的概率 MUST 等于其权重除以权重总和。候选池为空，或权重总和为 0，MUST 作为关卡加载错误报告。

#### Scenario: 按权重抽取
- **WHEN** 候选为金币权重 8、1UP 权重 2，统计一万次独立抽取
- **THEN** 1UP 约占 20%，误差在统计范围内

#### Scenario: 全零权重
- **WHEN** 候选池中每一项的权重都是 0
- **THEN** 关卡加载失败，错误指出该方块的坐标

### Requirement: 每条命抽一次

随机方块的内容物 MUST 在每条命开始时（关卡开始与每次重生时）抽取，这条命内 MUST 保持不变；顶击时 MUST NOT 再次抽取。多次金币砖的随机结果 MUST 对整条命内的每一次顶击都相同。

#### Scenario: 一条命里不变
- **WHEN** 一个随机方块本条命抽到星星
- **THEN** 无论玩家何时顶它，这条命里都产出星星

#### Scenario: 重生后重抽
- **WHEN** 玩家死亡并重生
- **THEN** 所有随机方块重新抽取，结果可能与上条命不同

### Requirement: 可复现

抽取结果 MUST 只由三样东西决定：本局的随机种子、当前是第几条命、方块在关卡中的位置。相同的种子、相同的命数，同一方块 MUST 抽到相同结果；结果 MUST NOT 依赖关卡中其他方块的数量或顶击顺序。

#### Scenario: 同种子同结果
- **WHEN** 用同一种子把同一关卡运行两次
- **THEN** 每条命里每个随机方块的结果都相同

#### Scenario: 不受其他方块影响
- **WHEN** 在关卡别处新增一个随机方块
- **THEN** 原有随机方块在同一种子下的结果不变

### Requirement: 随机块在编辑器中的配置

编辑器属性面板 MUST 提供"指定 / 随机"切换。选随机时 MUST 列出全部 6 种内容物供勾选，每项可设权重，默认等权，并实时显示每项的概率百分比。画布上随机方块 MUST 带有区别于指定方块的骰子标记。批量选中多个方块时 MUST 能一次设置。

#### Scenario: 勾选与概率
- **WHEN** 用户把一个问号块切换为随机，只勾选红蘑菇与 1UP，权重分别为 3 和 1
- **THEN** 面板显示红蘑菇 75%、1UP 25%，画布上该方块出现骰子标记

#### Scenario: 批量设置
- **WHEN** 用户框选 5 个问号块后在属性面板选择随机
- **THEN** 5 个方块都变为随机，并使用同一份候选池

### Requirement: 试玩中查看与重抽

试玩 MUST 提供固定种子与换种子两种方式，并 MUST 能开关"显示随机结果"：打开时，随机方块在被顶之前就显示本条命抽到的内容。这些选项 MUST NOT 写入关卡文件。

#### Scenario: 换种子
- **WHEN** 用户在试玩选项里点"换种子"后重新试玩
- **THEN** 随机方块的抽取结果可能与上次不同

#### Scenario: 固定种子复现问题
- **WHEN** 用户固定种子后反复试玩
- **THEN** 每次第一条命里同一随机方块的结果都相同

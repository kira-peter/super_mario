# Spec Delta

## Purpose

定义关卡中可交互的方块与道具：问号块与砖块的顶击效果、金币的获取、蘑菇与星星道具的生成与收集，以及顶击动画与连击计分。它们是玩家做出动作后获得世界反馈的主要途径。

## ADDED Requirements

### Requirement: 问号块

问号块 MUST 在被顶击时发放一次内容物，之后 MUST 变为已使用的空块，MUST NOT 再次发放。内容物 MUST 在关卡数据中预先确定（金币、蘑菇或星星），MUST NOT 在顶击时随机。

#### Scenario: 首次顶击发放内容
- **WHEN** 玩家顶击一个未使用的问号块
- **THEN** 方块发出一次顶击动画并生成其预设内容物

#### Scenario: 二次顶击无效果
- **WHEN** 玩家顶击一个已使用的问号块
- **THEN** 方块只有轻微顶动，不再生成内容物

#### Scenario: 内容物由关卡数据决定
- **WHEN** 同一关卡分别运行两次并顶击同一问号块
- **THEN** 两次发放的内容物类型相同

### Requirement: 顶击动画

被顶击的方块 MUST 播放一次短促的向上位移再回落，MUST 在动画结束后回到原位。动画 MUST 是纯视觉的，MUST NOT 改变方块的碰撞位置。

#### Scenario: 动画结束回到原位
- **WHEN** 方块顶击动画播放完毕
- **THEN** 方块绘制位置与动画前完全一致

#### Scenario: 动画期间仍可碰撞
- **WHEN** 方块处于顶击动画中
- **THEN** 玩家与其实体的碰撞判定使用原始位置

### Requirement: 金币

关卡中 MUST 有可收集的旋转金币，玩家接触 MUST 获得金币并计分。金币 MUST 有旋转的视觉动画，MUST NOT 影响碰撞。

#### Scenario: 接触金币
- **WHEN** 玩家与金币重叠
- **THEN** 金币消失，金币计数与分数增加

#### Scenario: 金币旋转动画
- **WHEN** 金币静止在关卡中
- **THEN** 其外观按固定节奏变化，表现出旋转

#### Scenario: 金币数量上限
- **WHEN** 金币计数达到平台上限（100）
- **THEN** 计数归零，玩家获得一次额外生命

### Requirement: 蘑菇道具

蘑菇 MUST 从被顶击的方块中升起，升起期间 MUST NOT 与玩家交互；升起完成后 MUST 开始朝当前方向水平移动，并 MUST 对玩家造成"变大"效果。蘑菇 MUST 与玩家使用相同的移动与碰撞规则，撞墙反向、走到边缘下落。

#### Scenario: 蘑菇从方块升起
- **WHEN** 问号块发放蘑菇
- **THEN** 蘑菇从方块位置缓慢升起，升起期间穿过玩家不产生效果

#### Scenario: 升起后开始移动
- **WHEN** 蘑菇升起到完整高度
- **THEN** 它开始水平移动，并可以被玩家收集

#### Scenario: 吃蘑菇变大
- **WHEN** 小形态玩家接触蘑菇
- **THEN** 玩家变为大形态并获得分数

#### Scenario: 大形态吃蘑菇
- **WHEN** 大形态玩家接触蘑菇
- **THEN** 蘑菇被消耗并获得分数，形态不变

### Requirement: 星星道具

星星 MUST 从方块中升起后开始移动，MUST 具备弹跳能力，能弹起落下并撞墙反向。收集后玩家 MUST 进入无敌状态，持续一段有限时间。无敌期间 MUST 与敌人接触即消灭敌人。

#### Scenario: 星星弹跳
- **WHEN** 星星从方块中升起并开始移动
- **THEN** 它会周期性地弹起与落地，撞到墙体反向

#### Scenario: 收集星星进入无敌
- **WHEN** 玩家接触星星
- **THEN** 玩家进入无敌状态，外观以固定频率闪烁

#### Scenario: 无敌到期恢复
- **WHEN** 无敌持续时间耗尽
- **THEN** 玩家回到普通状态，接触敌人重新会受伤

### Requirement: 连击计分

连续踩踏或连续用壳消灭敌人 MUST 使单次得分逐级递增，直到一个上限；连击 MUST 在玩家落地静止或被击中时重置。

#### Scenario: 连续踩踏得分递增
- **WHEN** 玩家在空中连续踩中第二个、第三个敌人
- **THEN** 每次的得分高于前一次

#### Scenario: 落地后连击重置
- **WHEN** 玩家落地并站立一段时间后再次踩敌
- **THEN** 得分从连击的第一级重新开始

#### Scenario: 连击有上限
- **WHEN** 连击次数超过计分表的最高档
- **THEN** 后续每次使用最高档分数，不再增长

### Requirement: 砖块碎块效果

被大形态击碎的砖块 MUST 产生四个向外飞散并受重力下落的碎块，碎块 MUST 在离开视野或超出存活时间后消失，MUST NOT 参与碰撞。

#### Scenario: 碎块飞散
- **WHEN** 砖块被击碎
- **THEN** 四个碎块向左右上下分散飞出并下落

#### Scenario: 碎块不影响玩家
- **WHEN** 碎块飞过玩家位置
- **THEN** 玩家不受影响，碎块不阻挡也不造成伤害

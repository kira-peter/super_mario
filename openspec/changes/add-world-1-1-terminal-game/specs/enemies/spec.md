# Spec Delta

## Purpose

定义敌人与玩家之间的交互：敌人的移动与转向、踩踏与侧面接触的区分、乌龟壳的状态流转与连锁击杀，以及屏幕外实体的休眠与激活。这是关卡难度曲线的主要来源。

## ADDED Requirements

### Requirement: 蘑菇怪的移动

蘑菇怪 MUST 以恒定水平速度朝当前方向移动，MUST NOT 改变速度大小。它 MUST 在碰到实体障碍时反向，MUST 在走到瓦片边缘时继续下落而不是悬空。

#### Scenario: 撞墙反向
- **WHEN** 蘑菇怪向右移动并碰到实体瓦片
- **THEN** 它在接触位置掉头，改为向左移动
- **AND** 速度大小不变

#### Scenario: 走到平台边缘下落
- **WHEN** 蘑菇怪走到一段地面瓦片的右端
- **THEN** 它从边缘落下，而不是在半空中继续水平前进

#### Scenario: 落到更低的地面继续前进
- **WHEN** 蘑菇怪从高处落到低处地面
- **THEN** 落地后恢复水平移动，方向不变

### Requirement: 踩踏判定

当玩家下落且脚部接触敌人顶部时 MUST 判定为踩踏；当玩家在其它接触方向或处于上升状态时 MUST 判定为受伤。判定 MUST 使用接触当步的垂直速度方向，而不是仅比较位置。

#### Scenario: 下落时踩中敌人
- **WHEN** 玩家以向下速度接触敌人顶部区域
- **THEN** 敌人被消灭并计分
- **AND** 玩家获得一次弹起

#### Scenario: 上升时从下方碰敌人
- **WHEN** 玩家以上升速度碰到敌人
- **THEN** 玩家受伤，敌人保持存活

#### Scenario: 并排行走时侧面接触
- **WHEN** 玩家与敌人水平速度接触且垂直方向没有明显的向下速度
- **THEN** 玩家受伤

#### Scenario: 踩踏后立即再踩
- **WHEN** 玩家踩中第一个敌人弹起，尚未落地又落向第二个敌人
- **THEN** 第二次踩踏同样有效，并累计连击计分

### Requirement: 乌龟的状态流转

乌龟 MUST 有两个状态：行走与缩壳。行走状态下被踩 MUST 变为缩壳并停止移动；缩壳状态下被踩 MUST 被踢出为滑行壳。滑行壳 MUST 保持缩壳形态高速移动。

#### Scenario: 踩乌龟进入壳
- **WHEN** 玩家踩中行走状态的乌龟
- **THEN** 乌龟变为缩壳，静止在原地
- **AND** 玩家弹起

#### Scenario: 踩静止的壳将其踢出
- **WHEN** 玩家踩或从侧面接触静止的壳
- **THEN** 壳开始朝远离玩家的方向滑行

#### Scenario: 滑行壳撞墙反弹
- **WHEN** 滑行壳碰到实体瓦片
- **THEN** 壳掉头继续滑行，速度不降低

### Requirement: 滑行壳的连锁击杀

被踢出的壳移动时 MUST 消灭它碰到的其他敌人，并按连击规则计分。壳撞到玩家时 MUST 造成伤害，除非玩家从上方踩停它。

#### Scenario: 壳扫过一排敌人
- **WHEN** 滑行壳依次撞到多个敌人
- **THEN** 每个敌人都被消灭且得分递增

#### Scenario: 壳撞到玩家
- **WHEN** 滑行的壳与玩家从侧面接触
- **THEN** 玩家受伤

#### Scenario: 踩停滑行壳
- **WHEN** 玩家从上方踩中正在滑行的壳
- **THEN** 壳停止移动，回到静止缩壳状态

### Requirement: 敌人被地形阻挡

敌人 MUST 与瓦片地形使用与玩家一致的碰撞规则。敌人 MUST NOT 穿墙、穿地。敌人掉出关卡底部时 MUST 被移除且不计分。

#### Scenario: 敌人不穿墙
- **WHEN** 敌人以恒定速度撞向竖直墙体
- **THEN** 敌人停在墙面并转向，不穿入墙内

#### Scenario: 掉出关卡的敌人被回收
- **WHEN** 敌人下落超出关卡底部
- **THEN** 该敌人从世界中移除
- **AND** 玩家得分不变

### Requirement: 屏幕外休眠与激活

处于相机可视范围之外且尚未被激活的敌人 MUST 保持休眠，不消耗模拟资源。当相机接近到激活距离时 MUST 开始正常模拟。一旦被激活，MUST 保持活跃，即使之后离开屏幕。

#### Scenario: 远处的敌人保持静止
- **WHEN** 关卡开始，相机停在起点
- **THEN** 视野之外的敌人在原位不动，直到相机接近

#### Scenario: 相机接近后开始移动
- **WHEN** 相机推进到敌人所在区域
- **THEN** 敌人从休眠进入活跃状态并开始移动

#### Scenario: 已激活的敌人离开视野仍在模拟
- **WHEN** 已被激活的敌人移动到相机后方
- **THEN** 它继续正常模拟，不会自动休眠

### Requirement: 敌人模型与颜色

不同敌人 MUST 在视觉上可区分，至少通过剪影形状区分，而不是仅靠颜色。颜色 MUST NOT 是唯一区分手段，以便在无彩色终端上仍然可辨。

#### Scenario: 无彩色终端仍可区分敌人
- **WHEN** 终端不支持颜色
- **THEN** 蘑菇怪与乌龟的剪影形状仍然不同，玩家可以区分

#### Scenario: 缩壳与行走可区分
- **WHEN** 乌龟在行走与缩壳之间切换
- **THEN** 剪影高度或形状明显变化，玩家可以判断其状态

# Spec Delta

## Purpose

定义第一关（World 1-1）的内容本身：关卡数据格式、地形与实体的完整布局、从起点到旗杆的节奏，以及通关判定。它把前面几条能力组织成一段有教学曲线的玩家体验。

## ADDED Requirements

### Requirement: 关卡数据格式

关卡 MUST 以可读的数据文件描述，MUST 至少表达：瓦片地形、实体的初始类型与位置、问号块的内容物、玩家出生点、旗杆位置、关卡右边界。数据 MUST NOT 包含任何可执行代码。

#### Scenario: 数据文件可独立修改
- **WHEN** 修改关卡数据中的某个瓦片或实体位置
- **THEN** 重新运行游戏后该改动生效，无需重新编译

#### Scenario: 数据不含代码
- **WHEN** 检查关卡数据文件
- **THEN** 其中只有声明式的属性与坐标，没有任何脚本或表达式

#### Scenario: 非法数据给出明确错误
- **WHEN** 关卡数据缺少出生点或包含越界坐标
- **THEN** 游戏在启动时报告具体错误位置并退出，而不是以损坏状态开始

### Requirement: 关卡尺寸与坐标

关卡 MUST 是一个水平延伸的长条，宽度 MUST 足够支撑约 25 秒的奔跑通过时间。坐标 MUST 以瓦片为单位，原点在关卡左上角，Y 轴向下为正。

#### Scenario: 关卡长条结构
- **WHEN** 观察关卡整体
- **THEN** 它是单一连续的水平区域，没有垂直滚动

#### Scenario: 通关时间合理
- **WHEN** 熟练玩家以奔跑速度前进并避开敌人
- **THEN** 从起点到旗杆的用时在数十秒的量级，而不是几秒或几分钟

### Requirement: 起点区教学

关卡起始的一段 MUST 是安全的、无敌人的平地，让玩家熟悉移动与跳跃，之后才出现第一个可顶击方块。第一个问号块 MUST 只包含金币，MUST NOT 包含任何需要玩家先理解的道具。

#### Scenario: 起点没有敌人
- **WHEN** 关卡开始且玩家位于出生点
- **THEN** 玩家前方一段距离内没有任何敌人

#### Scenario: 第一个方块给出简单奖励
- **WHEN** 玩家顶击关卡中的第一个问号块
- **THEN** 得到金币，且该方块不会产生蘑菇或星星

### Requirement: 渐进的地形难度

关卡 MUST 按从简到繁的顺序安排地形：先是平坦地面，随后是单一低水管，接着是逐渐加高的水管，最后是地面断层与阶梯。任何一次跳跃的跨度 MUST 不超过玩家以行走速度也能完成的范围，奔跑只用于获得更宽的容错。

#### Scenario: 低水管可轻松跨过
- **WHEN** 玩家以行走速度接近第一个低水管
- **THEN** 一次普通跳跃即可越过，不需要加速

#### Scenario: 最高水管仍在可跳范围内
- **WHEN** 玩家面对关卡中最高的水管
- **THEN** 通过助跑起跳可以越过，或者可以站上水管顶部继续前进

#### Scenario: 断层不用奔跑也能过
- **WHEN** 玩家以行走速度在断层边缘起跳
- **THEN** 可以落到断层另一侧

### Requirement: 敌人投放节奏

敌人 MUST 与地形配合投放：第一个敌人 MUST 出现在玩家已经学会跳跃之后，且在玩家接近前处于视野之外。敌人的出现 MUST 让玩家有时间反应，MUST NOT 在玩家落地的瞬间正好出现在脚下。

#### Scenario: 第一个敌人保持距离
- **WHEN** 玩家从起点前进并首次遇到敌人
- **THEN** 敌人从屏幕右侧进入视野，玩家有足够的反应距离

#### Scenario: 落点无伏击
- **WHEN** 玩家跳过障碍落地
- **THEN** 落点附近不存在刚刚从屏幕外进入的敌人

### Requirement: 水管群

关卡 MUST 包含四根水管，高度 MUST 依次递增。水管 MUST 是实体地形，玩家能站上顶部，MUST NOT 允许从侧面穿入。本关 MUST NOT 包含可进入的水管。

#### Scenario: 站上水管顶部
- **WHEN** 玩家跳上水管
- **THEN** 玩家稳定站在管顶，可以继续向右移动

#### Scenario: 水管侧面阻挡
- **WHEN** 玩家在地面走向水管侧面
- **THEN** 玩家被推开或停住，不穿入管内

#### Scenario: 本关水管不可进入
- **WHEN** 玩家在水管顶部按下下蹲动作
- **THEN** 不进入任何子区域，玩家停留在原地

### Requirement: 问号块与砖块组合

关卡 MUST 包含问号块与砖块的组合，其中 MUST 至少有一个问号块产出蘑菇（供玩家第一次变大），MUST 至少有一个砖块可产出多枚金币。道具 MUST 在玩家已经能理解方块之后才第一次出现。

#### Scenario: 第一次吃到蘑菇
- **WHEN** 玩家顶击产出蘑菇的问号块并收集蘑菇
- **THEN** 玩家变大，可以顶碎普通砖块

#### Scenario: 多金币砖块
- **WHEN** 玩家连续多次顶击该砖块
- **THEN** 该砖块依次产出多枚金币，直到耗尽

### Requirement: 隐藏奖励

关卡 MUST 包含至少一个隐藏奖励（隐形的额外生命方块或隐藏金币），MUST 只能通过顶击特定空区域的空气触发。隐藏奖励 MUST 不影响通关必需路径。

#### Scenario: 顶击空区域出现奖励
- **WHEN** 玩家在特定位置跳跃并头顶碰到空区域
- **THEN** 隐藏方块显形并产出奖励

#### Scenario: 错过隐藏奖励不影响通关
- **WHEN** 玩家完全没有触发隐藏奖励
- **THEN** 仍可正常到达旗杆并通关

### Requirement: 阶梯与断层

关卡 MUST 包含两段阶梯状地形与至少一处地面断层。阶梯 MUST 可以被逐级走上，断层 MUST 要求跳跃。

#### Scenario: 逐级走上阶梯
- **WHEN** 玩家走向阶梯
- **THEN** 玩家可以每次跳上一级并继续前进，不需要连续跳跃穿越

#### Scenario: 断层需要跳跃
- **WHEN** 玩家走到断层边缘并继续向右
- **THEN** 玩家掉入断层，除非跳起越过

#### Scenario: 掉入断层后死亡
- **WHEN** 玩家落入断层底部以下且没有落脚点
- **THEN** 玩家进入死亡流程

### Requirement: 旗杆与通关

关卡末端 MUST 有不可跳过的旗杆。玩家接触旗杆后 MUST 进入旗降动画：玩家沿旗杆滑下，随后走向城堡并消失，然后进入结算。

#### Scenario: 接触旗杆触发旗降
- **WHEN** 玩家跳跃或奔跑接触旗杆的任何高度
- **THEN** 玩家附着到旗杆上开始下滑，所有输入不再控制移动

#### Scenario: 旗降结束进入城堡
- **WHEN** 旗降动画完成
- **THEN** 玩家自动向右走入城堡并消失

#### Scenario: 跳过旗杆不可能
- **WHEN** 玩家以最高速度起跳试图越过旗杆顶部
- **THEN** 玩家仍会与旗杆发生接触，无法越过关卡末端

#### Scenario: 触碰高度影响得分
- **WHEN** 玩家在旗杆较高处接触
- **THEN** 获得的通关分数高于在较低处接触

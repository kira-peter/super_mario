# Spec Delta

## Purpose

定义玩家角色（马里奥）的运动学：地面的加速、减速与摩擦，可变高度的跳跃，空中的控制与惯性，以及形态变化对运动能力的影响。这套规则决定游戏的手感，是玩家唯一持续直接感知的物理契约。

## ADDED Requirements

### Requirement: 两级水平速度

玩家在地面 MUST 有两级速度上限：行走与奔跑。按住加速动作时 MUST 使用奔跑上限，松开时 MUST 回到行走上限。速度 MUST 由加速度逐步建立，MUST NOT 瞬时达到上限。

#### Scenario: 从静止起跑
- **WHEN** 玩家从静止按住右方向键与加速动作
- **THEN** 水平速度在连续若干步内单调增加，直到达到奔跑上限
- **AND** 达到上限后不再继续增加

#### Scenario: 松开加速回到行走速度
- **WHEN** 玩家在奔跑状态下松开加速动作但仍按住方向键
- **THEN** 水平速度逐渐下降到行走上限
- **AND** 不会突然被截断到行走上限

#### Scenario: 达到奔跑上限需要时间
- **WHEN** 玩家从静止起按住方向键与加速
- **THEN** 达到奔跑上限所需的步数明显大于达到行走上限所需的步数

### Requirement: 地面摩擦与松手减速

没有方向输入时，玩家 MUST 因摩擦逐步减速直到静止，MUST NOT 立即停止。减速速率 MUST 小于加速速率，使松手后仍有一段滑行。

#### Scenario: 松手后滑行
- **WHEN** 玩家在奔跑中同时松开方向键与加速动作
- **THEN** 水平速度在若干步内逐渐归零，期间玩家继续向前移动一段距离

#### Scenario: 静止后不再漂移
- **WHEN** 玩家速度已归零且没有方向输入
- **THEN** 玩家位置在后续步中保持不变

### Requirement: 反向输入的滑铲转向

当玩家按住与当前运动方向相反的方向键时，MUST 先以更大的减速度把速度降到零，再向反方向加速。MUST NOT 允许速度在一帧内瞬间反向。

#### Scenario: 全速奔跑时急转
- **WHEN** 玩家以奔跑上限向右移动并按下左方向键
- **THEN** 水平速度按减速速率减小到零并越过零点
- **AND** 转向过程占用多个模拟步，期间玩家继续向右滑行一段

#### Scenario: 转向不改变朝向前提前绘制
- **WHEN** 玩家正在滑铲转向但速度尚未过零
- **THEN** 角色朝向仍保持原方向，直到速度符号改变才翻转

### Requirement: 可变高度跳跃

跳跃 MUST 由按下动作启动，初速度 MUST 固定。在上升阶段持续按住跳跃动作时，玩家 MUST 比提前松开时跳得更高。松开跳跃动作或达到顶点后，上升 MUST 立即转为按重力下落。

#### Scenario: 轻点跳跃
- **WHEN** 玩家按下跳跃键并在很短的步数内松开
- **THEN** 玩家上升到一个较低的最高点后下落

#### Scenario: 长按跳跃
- **WHEN** 玩家按下跳跃键并持续按住直到角色的上升被截断或到达顶点
- **THEN** 玩家的最高点显著高于轻点跳跃的最高点

#### Scenario: 松开后立即折返
- **WHEN** 玩家在上升途中松开跳跃键
- **THEN** 当步的垂直速度被压缩，随后按重力加速下落，MUST NOT 继续上升到原定的最高点

#### Scenario: 空中不能再次起跳
- **WHEN** 玩家在空中再次按下跳跃键
- **THEN** 不产生新的跳跃，除非玩家正站在可站立表面上

### Requirement: 跳跃高度受水平速度影响

起跳时的水平速度 MUST 影响跳跃的垂直初速度，使奔跑起跳比原地起跳更高或滞空更久。该影响 MUST 在起跳当步根据起跳前的水平速度一次性确定。

#### Scenario: 奔跑起跳更远更高
- **WHEN** 玩家以奔跑速度起跳
- **THEN** 其跳跃的水平距离与最高点均大于原地起跳

#### Scenario: 空中提速不改变已确定的跳跃
- **WHEN** 玩家起跳后在空中继续加速
- **THEN** 垂直初速度保持起跳时确定的值，不因空中速度增加而重新计算

### Requirement: 空中控制

玩家在空中 MUST 能改变水平加速度的方向，但空中加速度 MUST 小于地面加速度。松开方向键时，空中 MUST 保留大部分水平速度，而不是像地面一样快速摩擦减速。

#### Scenario: 空中微调落点
- **WHEN** 玩家起跳后在上升途中按下反方向键
- **THEN** 水平速度改变方向但变化速率小于地面转向

#### Scenario: 空中松手保持冲量
- **WHEN** 玩家在奔跑起跳后到落地前松开所有方向键
- **THEN** 水平速度几乎不变，玩家在落地时仍保留大部分水平冲量

### Requirement: 落地与踩踏后的速度保留

玩家落地时 MUST 保留水平速度。踩踏敌人后 MUST 保留现有的水平速度，并可立即再次起跳，MUST NOT 因落地而被清零。

#### Scenario: 连续跳跃保留冲量
- **WHEN** 玩家落地后立刻再次起跳
- **THEN** 新的跳跃沿用落地时的水平速度

#### Scenario: 踩踏后弹起
- **WHEN** 玩家从上方踩中敌人
- **THEN** 玩家获得一次弹起，水平速度不变

### Requirement: 形态与受伤

玩家 MUST 有至少三种形态状态：小、大、无敌。受到伤害时，大形态 MUST 退回小形态并进入短暂无敌；小形态受到伤害 MUST 判定死亡。无敌形态下接触敌人 MUST NOT 造成伤害，且敌人 MUST 被消灭。

#### Scenario: 大形态受伤变小
- **WHEN** 大形态玩家从侧面接触敌人
- **THEN** 玩家退回小形态
- **AND** 在随后一段时间内再次接触敌人不会再次受伤

#### Scenario: 小形态受伤死亡
- **WHEN** 小形态玩家从侧面接触敌人
- **THEN** 玩家进入死亡流程

#### Scenario: 无敌状态碾压敌人
- **WHEN** 无敌形态玩家接触任何敌人
- **THEN** 该敌人被消灭并计分
- **AND** 玩家自身不受影响

#### Scenario: 无敌结束时闪烁提示
- **WHEN** 无敌状态剩余时间进入最后一段
- **THEN** 角色以固定频率闪烁，提示即将恢复普通状态

### Requirement: 形态变化改变碰撞体

从小变大或从大变小时，玩家的碰撞体高度 MUST 相应变化，并 MUST 在变化后重新求解与地形的重叠，MUST NOT 因变大而嵌入地面或平台。

#### Scenario: 在地面上变大
- **WHEN** 小形态玩家在实体地面上吃到蘑菇
- **THEN** 碰撞体变高，底边仍贴合地面，头顶不穿过上方瓦片

#### Scenario: 头顶空间不足时变大
- **WHEN** 小形态玩家在低矮通道内变为大形态且空间不足
- **THEN** 游戏不会把玩家卡死或推穿地形，而是按碰撞规则调整位置或延迟生效

# Spec Delta

## Purpose

定义终端渲染与视觉语言：如何把游戏世界合成到字符网格上、如何取色、如何跟随相机，以及终端能力不足或窗口过小的时候如何降级。它决定了游戏在终端里"看起来像什么"。

## ADDED Requirements

### Requirement: 字符像素合成

渲染 MUST 把游戏世界先合成到一块虚拟像素缓冲，再一次性转换为终端字符单元。转换 MUST 使用半块字符把纵向分辨率翻倍，使虚拟像素在常见终端下接近正方形。MUST NOT 逐实体直接绘制到终端。

#### Scenario: 虚拟缓冲合成
- **WHEN** 渲染一帧
- **THEN** 所有实体先绘制到虚拟像素缓冲，再整体转换为字符
- **AND** 后绘制的实体正确覆盖先绘制的实体

#### Scenario: 纵向分辨率翻倍
- **WHEN** 一个终端字符单元承载两个纵向虚拟像素
- **THEN** 上下两个虚拟像素颜色不同时，字符使用半块组合表现两种颜色

#### Scenario: 比例不失真
- **WHEN** 在标准终端窗口中运行
- **THEN** 圆形与方形的角色比例不会出现明显的纵向拉伸

### Requirement: 调色板与语义令牌

渲染 MUST 通过一组语义色令牌取色（至少包括：天空、地面、砖块、问号块、金币、玩家、敌人、道具、HUD 文字、背景）。MUST NOT 在实体绘制处硬编码颜色值。主题 MUST 可整体替换，且替换后所有元素同步变化。

#### Scenario: 令牌取色
- **WHEN** 检查任意实体的绘制代码
- **THEN** 其颜色来自语义令牌，不包含具体色值

#### Scenario: 切换主题全局生效
- **WHEN** 切换主题
- **THEN** 下一帧的全部元素使用新主题的颜色

#### Scenario: 前景背景对比清晰
- **WHEN** 以默认主题渲染游戏
- **THEN** 玩家、敌人与背景之间保持足够对比，玩家在任意关卡位置都能被辨认

### Requirement: 视口与相机变换

渲染 MUST 只绘制相机可见范围内的内容。实体坐标到屏幕坐标的变换 MUST 由相机偏移统一完成，MUST NOT 由各实体自行计算。绘制顺序 MUST 明确（背景、地形、道具、敌人、玩家、特效、HUD）。

#### Scenario: 屏幕外不绘制
- **WHEN** 实体完全位于相机可见范围之外
- **THEN** 该实体不参与绘制

#### Scenario: 分层绘制
- **WHEN** 玩家与敌人位置重叠
- **THEN** 玩家绘制在敌人之上，不出现被遮挡的情况

#### Scenario: HUD 不被遮挡
- **WHEN** 关卡内容延伸到 HUD 所在区域
- **THEN** HUD 始终绘制在最上层

### Requirement: 色彩能力降级

渲染 MUST 探测终端的色彩能力，并在真彩色不可用时降级到 256 色，在无彩色时降级到单色。降级 MUST NOT 丢失关键信息：玩家、敌人与可交互物 MUST 在单色下仍可区分。

#### Scenario: 真彩色终端
- **WHEN** 终端支持真彩色
- **THEN** 使用主题定义的具体色值渲染

#### Scenario: 256 色终端
- **WHEN** 终端只支持 256 色
- **THEN** 颜色被量化到最接近的可表示色，整体观感保持一致

#### Scenario: 单色终端
- **WHEN** 终端不支持颜色
- **THEN** 使用不同字符与粗细表现层次，玩家与敌人仍可区分

### Requirement: 字符能力降级

当终端无法渲染半块字符或制表符号时，渲染 MUST 退回到纯 ASCII 字符集。降级 MUST 在启动时探测一次，MUST NOT 在运行中随字符变化而抖动。

#### Scenario: 不支持半块字符
- **WHEN** 终端环境被判定为不支持 Unicode 半块字符
- **THEN** 渲染改用 ASCII 字符组合，游戏可正常游玩

#### Scenario: 降级后仍在同一坐标体系
- **WHEN** 渲染处于 ASCII 降级模式
- **THEN** 世界坐标与碰撞判定不受影响，仅视觉表现改变

### Requirement: 最小尺寸与调整

游戏 MUST 声明最小可用终端尺寸。尺寸低于最小值时 MUST 显示明确的提示，MUST NOT 渲染出破碎的画面。窗口尺寸变化时 MUST 重新计算布局并在下一帧正确渲染。

#### Scenario: 窗口过小
- **WHEN** 终端尺寸小于最小要求
- **THEN** 显示一行说明当前尺寸与所需尺寸的提示

#### Scenario: 窗口恢复
- **WHEN** 终端尺寸恢复到可用范围
- **THEN** 游戏立即恢复正常渲染，相机与玩家位置不变

#### Scenario: 运行中调整尺寸
- **WHEN** 用户在游戏中改变终端窗口大小
- **THEN** 下一帧按新尺寸重新排布，不出现残影

### Requirement: 帧刷新策略

渲染 MUST 与模拟解耦，默认渲染频率 MUST 低于模拟频率，以降低终端刷新压力。渲染 MUST 只更新发生变化的单元，MUST NOT 每帧重绘整屏。卡顿时 MUST 优先保证模拟的正确性而不是画面完整性。

#### Scenario: 渲染频率低于模拟频率
- **WHEN** 模拟以固定步长运行
- **THEN** 一帧渲染可以对应多个模拟步，画面显示最新的模拟结果

#### Scenario: 差量刷新
- **WHEN** 画面中只有局部区域发生变化
- **THEN** 仅这些区域被更新到终端

#### Scenario: 对话或挂起后恢复
- **WHEN** 终端从挂起或切换后恢复
- **THEN** 画面被完整重绘一次，不残留旧内容

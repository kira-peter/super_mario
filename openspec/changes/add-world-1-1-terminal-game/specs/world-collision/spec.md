# Spec Delta

## Purpose

定义瓦片世界与碰撞求解：实体如何与地形接触、顶击方块、进入水管，以及相机如何跟随与限制在关卡边界内。碰撞规则是所有实体共用的地基，它决定了跳跃是否可靠、地形是否可信。

## ADDED Requirements

### Requirement: 瓦片关卡

关卡 MUST 由规则网格上的瓦片组成，网格单元尺寸 MUST 与角色碰撞体使用同一坐标尺度。每种瓦片 MUST 属于明确的碰撞类别：实体地面、可顶击、可穿透、单向平台、危险、装饰。

#### Scenario: 实体地面支撑角色
- **WHEN** 玩家静止站在实体地面瓦片上
- **THEN** 玩家的垂直位置稳定，垂直速度归零
- **AND** 玩家不会在后续步中缓慢下沉或抖动

#### Scenario: 装饰瓦片不参与碰撞
- **WHEN** 玩家经过装饰瓦片所在的格子
- **THEN** 玩家的运动不受阻挡

### Requirement: 逐轴分离的碰撞求解

碰撞 MUST 按水平与垂直两个轴分离求解：先沿水平方向移动并解决水平重叠，再沿垂直方向移动并解决垂直重叠。MUST NOT 用单次任意方向的重叠检测同时修正两轴，否则斜向接触会被错判。

#### Scenario: 沿墙滑落
- **WHEN** 玩家贴着墙下落
- **THEN** 水平位置被贴墙约束，垂直方向仍能正常下落

#### Scenario: 落地不横向卡住
- **WHEN** 玩家以高速斜向下落到一排瓦片上
- **THEN** 玩家落在瓦片顶面并保留水平速度
- **AND** 不会被判定为撞到瓦片侧面

#### Scenario: 高速移动不穿透
- **WHEN** 玩家或敌人在单步内的位移大于一个瓦片
- **THEN** 碰撞仍能检测到中间的瓦片，实体不会穿过地形

### Requirement: 地面与天花板判定

玩家 MUST 能区分站立、上升顶到天花板、下落落地三种垂直接触。接触后 MUST 将对应方向的垂直速度归零，并把实体位置贴到接触面。

#### Scenario: 落在平台顶面
- **WHEN** 玩家下落时与瓦片顶面接触
- **THEN** 玩家被贴到顶面，垂直速度归零，判定为着地

#### Scenario: 跳跃撞到天花板
- **WHEN** 玩家上升时头顶碰到瓦片底面
- **THEN** 垂直速度归零，玩家开始下落
- **AND** 不会穿过该瓦片继续上升

#### Scenario: 着地状态可被再次起跳使用
- **WHEN** 玩家在着地当步按下跳跃
- **THEN** 跳跃正常执行

### Requirement: 单向平台

部分瓦片 MUST 只从上方阻挡，从下方与侧面 MUST 可以穿过。玩家在平台上方下落时 MUST 落在平台上，从下方上升时 MUST 穿过。

#### Scenario: 从下方跳上单向平台
- **WHEN** 玩家从平台下方跳跃并穿过平台
- **THEN** 上升过程中不受到阻挡
- **AND** 在下落并接触平台顶面时停住

#### Scenario: 站在单向平台上不会自动下落
- **WHEN** 玩家站在单向平台顶面静止
- **THEN** 玩家保持在台面上，不穿透下落

### Requirement: 顶击方块

当玩家上升并头顶碰到可顶击方块时，该方块 MUST 收到一次顶击事件；同一方块在很短时间内 MUST NOT 被同一次跳跃重复触发。顶击方块 MUST 同时终止玩家的上升。

#### Scenario: 跳跃顶到问号块
- **WHEN** 玩家上升时头顶碰到问号块
- **THEN** 该方块被触发一次，玩家垂直速度归零并开始下落

#### Scenario: 一次跳跃不重复触发
- **WHEN** 玩家顶到方块后由于位置修正在同一帧内再次与该方块重叠
- **THEN** 只产生一次顶击，不重复发放内容物

#### Scenario: 从下方顶砖块
- **WHEN** 玩家上升时头顶碰到普通砖块
- **THEN** 触发该砖块的顶击效果，玩家上升被终止

### Requirement: 大形态撑破砖块

大形态玩家顶击可破坏砖块时 MUST 将其击碎并移除；小形态顶击同样位置 MUST 只产生顶击动画，砖块保留。被击碎的砖块 MUST 产生碎块效果并加分。

#### Scenario: 大形态击碎砖块
- **WHEN** 大形态玩家顶击可破坏砖块
- **THEN** 砖块被移除并产生碎块
- **AND** 玩家得分增加

#### Scenario: 小形态只能顶动砖块
- **WHEN** 小形态玩家顶击可破坏砖块
- **THEN** 砖块播放顶击动画但保留在原位

### Requirement: 被地形挤压

当玩家被移动中的地形（或形态变大）挤到没有空间的位置时，MUST 判定为被挤伤，而不是允许穿模。该判定 MUST 区分大小形态的处理方式。

#### Scenario: 被挤压死亡
- **WHEN** 玩家被两侧或上下方向的实体瓦片同时夹住且无法退出
- **THEN** 玩家进入受伤或死亡流程，不穿模

### Requirement: 相机跟随与边界

相机 MUST 水平跟随玩家，MUST 在玩家前进时保持玩家位于屏幕的舒适区域，MUST NOT 回退到已经离开的区域（原版式单向滚动）。相机 MUST 被限制在关卡边界内，MUST NOT 显示关卡外的空白。

#### Scenario: 前进时相机前推
- **WHEN** 玩家向关卡右侧移动并到达屏幕中部的推进阈值
- **THEN** 相机随之向右移动，玩家保持在中部附近

#### Scenario: 后退不拉回相机
- **WHEN** 玩家向左退回已经走过的区域
- **THEN** 相机保持在当前位置，玩家向屏幕左侧移动

#### Scenario: 关卡起点与终点边界
- **WHEN** 相机到达关卡最左或最右端
- **THEN** 相机停止，画面边缘与关卡边界对齐

#### Scenario: 玩家不越出关卡左边界
- **WHEN** 玩家在关卡起点持续向左走
- **THEN** 玩家被关卡左边界阻挡，无法走出关卡
